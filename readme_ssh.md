# Zapret Manager для Forkop X

Форк проекта StressOzz. Авторство исходного проекта сохраняется.

В LuCI и Web UI оставлены пять разделов: Дашборд, Zapret, Zapret2,
Hosts и Терминал. Консольный `zms` использует тот же backend и настройки.
Стратегии, тесты и редактирование Hosts доступны через панель.

## Установка и обновление

Установка из раздела компонентов Forkop X включает также Web UI и LuCI.
Команда `zmw` переустанавливает/обновляет панель. В `zms` для этого служит `w`.
Обновление не удаляет панель при повторном выборе `w`.

Проверка новых версий в панели использует `main` этого форка
`Screamshow/Zapret-Manager`. Изменения только в `dev` пользователям не поступают.
Файлы скачиваются через зеркало Forkop с резервным доступом к GitHub.

После обновления страницы исключённых компонентов удаляются, меню и
ресурсы обновляются. Настройки Zapret, Zapret2 и Hosts сохраняются.
Удаляются только задания cron, вызывающие исключённые команды backend
панели. Самостоятельно установленные службы и их расписания сохраняются.

## Консоль

- `zms` — пять пунктов консольного меню.
- `zms --status` — состояние Zapret и Zapret2.
- `zms --install-web` — установка/обновление панели.
- `zms --auto-best` — совместимость со старым расписанием подбора стратегий.

Для работы консоли нужен общий backend; при первом запуске он устанавливается
вместе с панелью. Старый отдельный консольный движок больше не поставляется.
