# Очистка backend форка — 29.10.2026

Рабочая ветка: `dev`, исходный серверный коммит `c9b7927` плюс перенесённая
незакоммиченная очистка. Подготовленная версия панели: 4.71.1.

## Изменения

- Из backend удалены установщики, настройки и обслуживание исключённых
  компонентов. Вместо 1506 функций в исходном серверном backend осталось 445.
- Watchdog, диагностика и обновление версий обслуживают оставшиеся компоненты.
  Автообновление фильтрует также старый кеш: допускаются панель и Zapret2.
- Сохранены стратегии Zapret, в том числе обход блокировки DoH, тесты,
  восстановление стратегии после прерывания, Hosts и управление ttyd.
- Консоль использует общий backend, старый отдельный движок удалён.
  Сохранены авторство StressOzz и совместимость `--auto-best`.
- Удалены лишние RPC ACL для запуска ByeTube, netshift.uc, b64.uc,
  создаваемые ресурсы redbtn и отдельные устаревшие установщики/ресурсы
  Mixomo, MagiTrickle, AutoBypass и proxy_zms.
- При обновлении удаляются старые страницы и кеш версий. Удаляются только
  cron-вызовы исключённых команд этой панели; расписания самостоятельных служб
  сохраняются. Загрузчики zms/zmsA/zmw передают аргументы.
- В локальном Forkop X исправлен адрес загрузчика zmw: Screamshow вместо
  StressOzz. Проверка активации/удаления панели из Forkop пройдена.

## Проверки

`node tests/panel-contract.cjs`: синтаксис вложенных JS/JSON, пять вкладок
в обоих меню, наличие используемых API/RPC и прав ACL, отсутствие реализаций
исключённых компонентов, соответствие команд установщика диспетчеру backend.

`node tests/backend-behavior.cjs` с доступным POSIX sh: синтаксис shell,
фильтрация старого кеша обновлений, повторная миграция cron, сохранение
посторонних расписаний и использование общего backend консолью.

На существующей VMware OpenWrt 25.12.5 x86/64 (192.168.1.1):

- Перед установкой сохранены пакеты, UCI, службы, nft и конфигурация для отката.
- Свежая установка успешна, RPC зарегистрирован, Web UI доступен по HTTP 7788.
- status, system_info, system_status, hosts_status, health, test_status,
  term_status и versions вернули JSON без отсутствующих команд.
- Вызов health через ubus успешен.
- Повторная установка удаляет подложенные старые страницы и задания cron,
  сохраняет пять текущих страниц, настройки и постороннее расписание.
- Исключённые steer_action и adblock_action отвергаются диспетчером.
- Консольное меню вызывает status и health; HTTP отдаёт пять маршрутов Web UI.
- Тест Forkop `tests/zapret_manager_web.sh` пройден на VM.
- После теста удалены тестовая панель и её загрузчики, восстановлена конфигурация
  служб. Списки пакетов и экспорт UCI совпали с исходными; DNS отвечает,
  объект RPC панели отсутствует. Клиентские роутеры не изменялись.

## Ограничения

Пакет unzip не удалось установить из фидов этой VM. Панель сообщила об этом;
пакеты не изменились. Установка самих Zapret/Zapret2, реальные проверки
стратегий и визуальная работа страниц в браузере в этот прогон не входили.
Проверка миграции использует смоделированные остатки старой панели, а не
установку полного прежнего менеджера с его сторонними компонентами.

Публикация в main/GitHub/зеркало не выполнялась. Пока изменения находятся
только в dev, пользователи их не получают.
