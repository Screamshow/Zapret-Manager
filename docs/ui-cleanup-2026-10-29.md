# Очистка оставшегося интерфейса — 29.10.2026

Изменения выполнены в локальном `dev` после очистки backend 4.71.1.
Исходная серверная работа и предыдущие незакоммиченные изменения сохранены.

## Что удалено

- 27 неиспользуемых экспортов общего модуля и 37 связанных объявлений.
  Среди них Steer offload, редактор ссылок, селекторы маршрутов, метаданные
  подписок, старые карточки предупреждений и состояние удалённых функций.
- Два неиспользуемых помощника дашборда, подписи исключённых заданий,
  отсоединённый узел авторской строки и 18 неиспользуемых SVG-иконок.
- 1194 неиспользуемых CSS-правила, устаревшие ветви общих селекторов и
  анимации, которые больше не используются. Общие правила пяти оставшихся
  страниц сохранены. Динамические классы уведомлений и changelog учтены.
- Документ AutoBypass и 15 изображений исключённых разделов.

Размер суммарных JS/CSS-полезных данных установщика уменьшился с 642457
до 502947 байт (на 139510 байт): common.js — 107232 → 80973;
style.css — 130310 → 45392; app.css — 166721 → 141999.

## Проверки

- Проверки shell, JS/JSON, API/RPC и контрактов миграции пройдены.
- ESLint `no-undef` не обнаружил неопределённых имён во всех JS payload.
- `tests/ui-render.cjs` выполняет реальные модули в jsdom с детерминированными
  RPC-ответами: пять страниц в LuCI и Web UI, открытие вкладки YouTube
  с 32 стратегиями, запуск оболочки Web UI и переход по пяти маршрутам.
- Сравнение DOM до/после: текст и классы совпадают, кроме намеренной замены
  старых названий компонентов в подсказках. Это тест DOM, не визуальный тест
  реального браузера и не проверка изменения стратегий на настоящем трафике.
- `git diff --check` пройден. Для DOM-тестов используется jsdom 26.1.0;
  зависимости и запуск описаны в `tests/package.json`.
